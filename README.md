# 📱 Social Media Dropdown Menu

A simple and interactive **Social Media Dropdown Menu** built using **HTML, CSS, and JavaScript**.

Click on the **"Select Social Media"** button to open the dropdown menu and display different social media options. Clicking the button again closes the menu.

---

## ✨ Features

- 🖱️ Click to open the dropdown menu
- 🔽 Displays social media options dynamically
- ❌ Click again to close the menu
- 📱 Clean and simple user interface
- 🎨 Custom CSS styling
- ⚡ Interactive behavior using JavaScript
- 🚫 No external libraries required

---

## 🌐 Social Media Options

The dropdown menu includes:

- 🔵 **Facebook**
- ▶️ **YouTube**
- 📸 **Instagram**
- 🐦 **Twitter**
- 📌 **Pinterest**
- 🟢 **WhatsApp**

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

---

## ⚙️ How It Works

The project uses **JavaScript click events** to control the visibility of the dropdown menu.

### When the button is clicked:

- If the menu is **closed**, it opens and displays the social media options.
- If the menu is **already open**, it closes the menu.

This creates a simple **toggle effect** using basic JavaScript.
